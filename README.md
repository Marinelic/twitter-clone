A simple Twitter-like app built with React, styled with TailwindCSS, and connected to MockAPI for storing tweets online.
You can post, like ❤️, and delete 🗑️ tweets — and they stay saved even after refresh!


✨ FEATURES

- Create new tweets
- Like and unlike tweets
- Delete tweets
- Data saved with MockAPI
- Avatar, display name, handle, and “time ago” display
- Character limit (280) with live counter
- Built with React + Vite + TailwindCSS

🛠️ TECHNOLOGIES USED

- React (hooks, components, state)
- TailwindCSS for styling
- MockAPI for backend
- Vite for fast local development
